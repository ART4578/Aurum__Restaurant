# Aurum Restaurant

## 1. Project Description

Aurum is a modern luxury restaurant landing page designed to provide an elegant, immersive, and responsive dining experience.

The website features a premium 2026-inspired visual design, responsive layouts, interactive menu filtering, mobile navigation, reservation modal, form validation, testimonials, restaurant information, and smooth scrolling.

The website is designed to work across different screen sizes and device types, including desktop computers, laptops, tablets, mobile phones, and other responsive displays.
